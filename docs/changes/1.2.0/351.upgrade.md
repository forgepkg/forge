The repository moved to `forgepkg/forge`, and so did its packages: from
1.2.0 on, the image is `ghcr.io/forgepkg/forge` and the Helm chart
`oci://ghcr.io/forgepkg/charts/forge`. The releases up to 1.1.0 stay at
`ghcr.io/schmitch/forge` and `oci://ghcr.io/schmitch/charts/forge`.
Upgrade the chart from the new name (`helm upgrade forge
oci://ghcr.io/forgepkg/charts/forge --version 1.2.0`); a kustomize overlay
or registry allowlist that names `ghcr.io/schmitch/forge` needs the new
name.
