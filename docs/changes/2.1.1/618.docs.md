Two step-by-step guides connect GitLab CI to Forge's NuGet feeds.
[GitLab CI with workload identity](docs/gitlab-ci.md) lets every job of a
project restore with a read-only role, and only the release job, on a
protected tag or environment, push the packages a trusted publisher names.
[CI with service accounts](docs/ci-service-accounts.md) does the same with a
read token and a release token for pipelines that cannot use workload
identity, and says how both methods run side by side.
