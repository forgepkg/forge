**Breaking:** the database schema starts over at a single migration, and
2.0.0 upgrades no existing database: start it on a new, empty one
(`database.url`, `FORGE_DATABASE__URL`). Startup refuses a database created
by 1.x or by a build before 2.0.0 with a message that says so ("the database
was created by Forge 1.x or by a build before 2.0.0, and 2.0.0 does not
upgrade it"), instead of failing with "migration 1 was previously applied
but has been modified".
