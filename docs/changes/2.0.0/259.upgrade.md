`server.max_upload_bytes` (`FORGE_SERVER__MAX_UPLOAD_BYTES`), deprecated in
1.1.0, is removed, and startup refuses a config that still sets it. Give a
package repository that needs another limit one of its own instead
(*Maximum upload size* in the web UI, `max_upload_bytes` in the admin API).
A package repository without a limit of its own accepts pushes of 512 MiB.
