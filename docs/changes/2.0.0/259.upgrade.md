`server.max_upload_bytes` (`FORGE_SERVER__MAX_UPLOAD_BYTES`), deprecated in
1.1.0, is removed, and startup refuses a config that still sets it. Before
upgrading, give every package repository that relied on it a limit of its
own (*Maximum upload size* in the web UI, `max_upload_bytes` in the admin
API), then remove the setting. A package repository without a limit of its
own accepts pushes of 512 MiB.
