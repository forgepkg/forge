NuGet sources and CI variables from `/v3/<name>/` to
`/repository/<name>/`, npm registry URLs from `/npm/<name>/` to
`/repository/<name>/`, and raw download URLs from `/raw/<name>/` to
`/repository/<name>/`. Update path-scoped npm credentials in `.npmrc` too:
for example, `//forge.example.com/npm/npm-all/:_authToken=...` becomes
`//forge.example.com/repository/npm-all/:_authToken=...`. Update reverse
proxies to route `/repository/` to Forge for all feeds; Docker remains at
`/v2/`. The old paths are not redirected.
