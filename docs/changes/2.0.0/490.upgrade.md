**2.0.0 is a fresh install: it does not upgrade a 1.x install.** Give it an
empty PostgreSQL database and an object-store bucket (or prefix) of its own,
never those of a 1.x install, and push the packages and images you keep to
it with their clients. The configuration carries over (`forge.toml`, the
`FORGE_*` variables, Helm values, kustomize overlays) with the changes these
notes list. With the PostgreSQL of the Helm chart or of the kustomize
manifests, deploy 2.0.0 next to the 1.x install, under another release name
or namespace, rather than upgrading it: that database keeps its volume
across `helm upgrade` and `helm uninstall`.
