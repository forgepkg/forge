Membership in the built-in `admin` role is the only thing that makes a user
an administrator. Migration 0039 gives the role to every user the
`app_user.is_admin` column still marked as an administrator without it, then
drops the column. The `is_admin` of the users API and of `/auth/me` and
`/admin/me` reports the role, and `POST /admin/users` with
`"is_admin": true` assigns it.
