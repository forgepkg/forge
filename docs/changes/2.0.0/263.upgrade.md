Legacy open access is gone: on an install whose data predates RBAC
(`SELECT value FROM forge_setting WHERE key = 'legacy_open_access'` answers
`true`), accounts created from now on (in the admin API, or provisioned by an
OIDC or credential-forwarding realm) no longer get the built-in
`authenticated` role (read and write on every repository) automatically.
Accounts that hold it keep it. Assign roles to new accounts, or give a
realm's users theirs, as on any other install.
`GET`/`PUT /admin/settings/legacy-open-access` are removed, and migration
0038 drops the setting and the routine that mapped pre-RBAC data.
