Raw file repositories are a format plugin, `plugins/raw`, like NuGet: the
plugin speaks the `/raw` protocol (paths, checksum sidecars, listings,
Nexus' form fields, a proxy's upstream URLs) and the server's new file store
keeps the files. `/raw` answers as before. The plugin contract,
`forge:format@0.4.0`, gains a second storage model for this: a plugin whose
`plugin.toml` says `storage = "files"` asks the host for files and
directories, stores and deletes files, and serves a file with `serve-file`;
`render` may now answer with any action `handle` can. `GET /admin/formats`
and the repositories API report what a repository holds (`storage`:
`packages`, `files` or `images`). See
[docs/format-plugins.md](docs/format-plugins.md#files-formats).
