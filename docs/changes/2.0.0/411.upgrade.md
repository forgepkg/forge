A grant gives one of three ordered access levels instead of one verb:
`read` < `write` < `delete`, each including the ones below it, and
administration is only membership in the built-in `admin` role. Token
scopes change the same way: `actions` becomes `level` (`read`, `write` or
`delete`), with `"admin": true` for the admin opt-in that `"admin"` in
`actions` gave. The grants API
(`/admin/roles/{id}/grants`), token creation and
`PATCH /admin/tokens/{id}/scope` take and return `level`, and answer 400
naming it to a request that still sends `action` or `actions`;
`/admin/users/{id}/effective` reports levels.
