WebAssembly format plugins: the memory ceiling (`memory_mib`) did not bound
the host memory a component could take. It applied to each of up to 16
linear memories on its own, left tables unbounded (a `table.grow` to
hundreds of millions of elements), and did not cover what a call returns: a
list whose elements all point at one large string was copied into the host
once per element. A buggy or malicious component could so make Forge run
out of memory on its first call. Now an instance's memories and tables
count against its ceiling together, and the strings and lists one call
returns, and the random bytes it asks WASI for, are bounded by it too; a
component that goes past it fails that call like any other trap.
