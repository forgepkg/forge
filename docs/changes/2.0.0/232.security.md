Helm: a chart archive holding two `Chart.yaml` files (in two top-level
directories, or the same name twice) was stored and listed under the first
one's name and version, while Helm installs the last one's. A publisher
whose package selector allows only `good` could so publish a chart that Helm
installs as `evil`, and a Helm proxy could cache an upstream chart under a
name and version Helm does not see. Forge now reads the whole archive the
way Helm does and refuses one with more than one top-level directory or
`<chart>/Chart.yaml`, or with a `requirements.yaml` that declares more than
dependencies, which Helm reads into the chart's name and version too.
