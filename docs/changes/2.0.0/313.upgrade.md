**Breaking:** `auto_provision` is gone from the `[oidc]` and
`[auth.upstream_basic]` blocks, and so are `FORGE_OIDC__AUTO_PROVISION` and
`FORGE_AUTH__UPSTREAM_BASIC__AUTO_PROVISION`. Whether a realm creates an
account on a user's first login is set for each realm, with **Auto-provision
users on first login** on its page under **Admin → Authentication**. Remove
the key before upgrading: a configuration that still sets it fails to load,
like one with any other unknown key. An existing realm keeps the value it
has, and a changed `[oidc]` block re-applied to its realm no longer changes
it. A realm the `[oidc]` block creates starts with auto-provisioning on; to
have it off, turn it off on the realm's page, or create the realm in the
admin UI instead of from the block.
