Helm: a `Chart.yaml` key that Helm reads as one of its fields without being
its name, such as `verſion` (with a long s) next to `version`, was ignored,
while Helm installs the chart with that key's value. Helm matches the keys
case-insensitively, by Unicode case folding, and the later key in sorted
order wins: so a chart pushed or proxied as `good` 1.0.0 installed as 6.6.6,
past the redeploy policy, retention and the package delay, and
`apiversion: v1` made a v2 chart a v1 chart for Helm. Forge now refuses a
`Chart.yaml` with such a key (400 on a push).
