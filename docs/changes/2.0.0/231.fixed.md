Helm and other format plugins: a version several kilobytes long passed
validation and failed its database insert, so a push answered 500 instead
of 400, and so did a proxy asked for such a version. A Helm chart version
may now be at most 128 characters, an OCI tag's limit, and every format
plugin's ids at most 512 bytes and versions at most 256: a longer one is
refused with 400 on push, answers 404 in a URL, and is left out of a
proxy's upstream version listings.
