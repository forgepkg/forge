Anonymous access, the login screen, password Basic authentication, the
session lifetimes and the login lockout are no longer configured in
`forge.toml`: an administrator sets them under **Admin → Settings** (or
`GET`/`PUT /admin/settings/auth`). Their keys are removed, and startup refuses
a configuration that still sets one, `FORGE_AUTH__*` and `FORGE_OIDC__*`
variables included: `auth.anonymous_mode`, `auth.anonymous_ip_allowlist`,
`auth.login_mode`, `auth.allow_password_basic`,
`auth.session_idle_ttl_seconds`, `auth.session_absolute_ttl_seconds`,
`auth.login_max_failures`, `auth.login_failure_window_seconds`, and
`oidc.session_idle_ttl_seconds` / `oidc.session_absolute_ttl_seconds`. Their
values are not carried over: after the upgrade an install has anonymous
access off, the identifier-first login screen, password Basic off, 8 h / 7 d
sessions and a lockout after 10 failed passwords in 5 minutes. Note the values
you set, remove the keys, start the new version, and set them again under
Admin → Settings. `auth.trusted_proxy_cidrs` and `server.allowed_hosts` stay
in the configuration.
