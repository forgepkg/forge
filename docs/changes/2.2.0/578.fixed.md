A database pool that ran out of connections while checking a request's
credentials (an API key, HTTP Basic, a Bearer token on a plugin route or a
browser session) answered 503 but did not count the timeout in
`db.client.connection.timeouts` (`db_client_connection_timeouts_total`), so
the `ForgeDatabasePoolExhausted` alert stayed silent while every
authenticated request failed. These timeouts now count like those on the
other request paths.
