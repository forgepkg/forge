With a few dozen to about a hundred proxy repositories, the per-repository
metrics (`http.client.request.duration`, `forge.proxy.lookups`) passed the
OpenTelemetry SDK's limit of 2,000 attribute sets per instrument: what was
recorded with a further one, a proxy's first 429, landed in a single
`otel.metric.overflow=true` series without repository or status, with
nothing logged, so alerts and dashboard panels by `forge_repository` missed
it. Every instrument that carries `forge.repository` now has room for 1,000
repositories, Forge logs a warning once per instrument when an attribute set
overflows all the same, and the deployment guide (Telemetry) names the
threshold past which to turn `telemetry.per_repository` off.
