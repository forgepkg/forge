Deleting a manifest of an image from the web UI's image page or with
`DELETE /admin/repositories/{name}/images` while a push added an index
listing one of its platform manifests could delete that platform manifest:
the new tag stayed, and pulling it failed for that platform. The delete now
decides on the image as it is once it holds the image's locks, and a
manifest pushed meanwhile stays with what it lists. A delete of a manifest
or an image that deadlocked with a push answered 500; it is run once more.
