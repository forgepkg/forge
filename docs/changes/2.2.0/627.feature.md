The rules of a workload-identity realm can be edited as JSON in the web UI:
**Edit as JSON**, in the realm's **Rules**, shows them as the admin API takes
them, to copy into another realm or another Forge, and replaces them with
pasted ones: the rules, a realm's config or a whole realm (the guides'
examples paste as they are), or one rule. JSON it cannot read is reported
with where it is (`rules[2].conditions[0].any_of`) and changes nothing.
Applying saves nothing: the rules are checked and saved with the realm, like
typed ones.
