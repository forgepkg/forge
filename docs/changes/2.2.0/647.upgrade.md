The **Accept passwords over HTTP Basic on the feeds** setting
(`allow_password_basic` in `/admin/settings/auth`) is gone: the upgrade
copies its value onto the local realm's new **Accept passwords from clients
(HTTP Basic)** (`accept_client_passwords`, **Admin → Authentication**), and
`PUT /admin/settings/auth` refuses the key. Credential-forwarding realms
accept their users' passwords from clients, as before. With
`allow_password_basic` off, the local realm's passwords were accepted over
Basic anyway while a credential-forwarding realm was enabled; now they are
not, and local users sign their clients in with tokens unless the local
realm is set to accept passwords. Scripts that set `allow_password_basic`
set the realm instead (`PATCH /admin/realms/{id}`).
