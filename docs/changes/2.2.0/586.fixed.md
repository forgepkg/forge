**Admin → Service accounts** showed an account a trusted-header realm names
as just used ("Last used") for every request the proxy's headers named it
in, also the ones that ran as someone else: an npm request with its own
Bearer token, or a docker request with a registry token. From a network the
load balancer admits as a service account, the account so looked in use
while nobody relied on it. A use is now recorded only for a request that
runs as the account.
