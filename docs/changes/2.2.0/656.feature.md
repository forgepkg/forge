An import copies a raw repository's files into a hosted raw repository.
Raw has no listing of its own, so the import reads Nexus' asset listing
(`/service/rest/v1/assets`) of a Nexus raw repository, another Forge's JSON
listing, or the paths it names, for a plain web server, where a file is
checked against its `.sha256` sidecar. A file is verified against its size
and the checksums listed, and stored through the same rules as an upload
(the administrator's selectors, the read-only policy, deduplication, the
audit trail, with the uploader); one Forge holds with the listed SHA-256 is
not downloaded again, and a changed file follows `on_conflict`. The source's
content type is kept, its upload time (`blobCreated`, `last_modified`,
`Last-Modified`) becomes the file's, and its last download too, or the
import time where it names none, so retention does not delete it right
after the import. A path Forge refuses fails as its own item. The web UI
offers **Import** on raw hosted repositories.
