A long range on **Admin → Traffic** read every row of every day file of the
range into memory before it summed them, enough on a busy instance to have
it killed for want of memory. Each day file is now summed as it is read and
its rows dropped, and one request sums 20,000 client networks at most: past
them, the ones with the fewest requests drop out of the top clients, and the
counts of clients turn into estimates (off by about 1 %), which the page
marks. **Top clients** shows the requests of the networks it leaves out as
**Other networks**.
