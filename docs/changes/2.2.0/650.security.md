`npm audit` through a group told the proxy's upstream about packages under
reserved prefixes in three cases: the legacy audit requests (`audits/quick`
and `audits`, sent by npm 6, by `pnpm audit` and by npm when a bulk request
fails) went out unchanged, with the whole dependency tree; a nested group's
reserved prefixes were not applied when auditing through an outer group; and
a bulk request whose body was not a JSON object went out unchanged. An audit
through a group now leaves out the packages under the reserved prefixes of
every group on the way to the proxy, in a bulk request and at every depth of
a legacy request's tree (aliases of such packages too), and a body that
cannot be filtered is refused with 400, never passed on.
