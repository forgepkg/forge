A docker pull of an image a content selector of the caller's grant hides
was refused with 403 (`DENIED`, 401 for an anonymous caller) when the
selector was on the repository pulled from, a group's included; through a
group's member it answered 404. Such an image is now not found on every
endpoint (manifests, blobs, tags and referrers answer 404 `NAME_UNKNOWN`),
as a package a selector hides is in the other formats. A request that sends
no credentials of its own (anonymous, or an account a trusted-header realm
names) still gets the 401 challenge, so a client that sends its credentials
only then, as containerd and Kubernetes do, pulls such an image with them. A
push or a delete outside the selector is still refused with 403.
