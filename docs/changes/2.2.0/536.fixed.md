Browsing a NuGet group in the web UI loaded every version of each member's
first 1,000 packages on every page, and listed no package past them: a
member's 1,001st package was reachable only by browsing the member itself,
and the group's total stopped there. A group now lists, counts and pages
the ids of all its members' packages, and loads versions for the packages
on the page alone. Its members are searched a few at a time rather than one
after another. NuGet searches of a group over hosted members, or over an
offline proxy, change the same way.
