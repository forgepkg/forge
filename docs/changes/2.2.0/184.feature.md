A proxy's package delay has per-package overrides and early releases.
`package_delay_overrides`, edited under the proxy's **Package delay**, is an
ordered list of other delays: the first entry that matches a package, by a
content selector (`"selector": "trusted-vendors"`) or by a glob of its own
(`"pattern": "Microsoft.*"`), decides its delay. `0` exempts trusted
publishers, a longer value holds a package back longer, and every other
package keeps `package_delay_seconds`. An administrator can also release one
version early, with a reason, from **Release now** on the package's page or
`POST /admin/repositories/{name}/packages/{id}/versions/{version}/release-delay`:
it is served at once while the package's other versions keep their delay, a
version the upstream has not published yet included. Listings,
registration, search and downloads honour both, and a change applies at
once, without waiting for the metadata TTL. A content selector an override
names cannot be deleted. See [docs/package-delay.md](docs/package-delay.md).
