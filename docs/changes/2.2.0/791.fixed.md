A Docker group whose proxy member's upstream broke off in the middle of a
layer, or sent a layer that does not match its digest, failed the pull: the
member serves the layer while it downloads it, so the failure only cut the
response short, and every retry asked the same member again. A member whose
download of a layer failed is now asked for that layer after the group's
other members for the next 5 minutes, so the client's retry is served by the
next member.
