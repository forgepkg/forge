A raw listing named entries a content selector hid from the caller: a
page's `next` (and its `Link` header and HTML link) was the last entry the
page read, hidden or not, so following `after=` walked through every hidden
name of a directory, in a hosted, proxy or group repository alike, and a
directory of hidden files alone answered `301` or an empty page rather than
`404` once it held more than a page of them. A page now reads on past
hidden entries until it holds `limit` visible ones (up to 1,000 entries),
its `next` is the last of them, and a directory with no visible entry is
not found. `npm audit` through a group, or a proxy, sent the upstream the
packages a selector of the caller's hid, with the proxy's credentials: an
audit now leaves out the packages the caller's selectors hide on any
repository on the way to the proxy, the proxy's own included, as it leaves
out reserved prefixes.
