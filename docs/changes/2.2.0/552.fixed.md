A Helm chart's page reads the chart archive as Helm does. To Helm (Go's
`archive/tar`), a directory, a link, a device or a FIFO has no body, whatever
size its header gives: the next entry starts right after its header. Forge
skipped the size the header gave, so an archive could show on the chart page
another README or `values.yaml` than Helm reads. Forge now reads those entries
with no body, takes an old-style entry whose path ends in `/` for a
directory, and reads a link or device named like the README or `values.yaml`
as an empty file, as Helm loads it.
