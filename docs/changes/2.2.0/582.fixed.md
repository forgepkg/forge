`forge.worker.interval` was recorded once, when a worker started, so with
delta temporality (`OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE=delta`)
only the first export carried it, and the `ForgeWorkerStalled` alert, which
compares it with `forge.worker.last_success.time`, stopped matching. It is
now reported on every export for every running worker, with the same name,
unit and `forge.worker` attribute.
