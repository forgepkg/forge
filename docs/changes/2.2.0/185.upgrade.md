A version now records when it was unlisted (`component.unlisted_at`, kept
by a database trigger on every path that unlists), for retention's
`unlisted_for_days`. The upgrade gives versions that are unlisted already
the time of their last change (`updated_at`): every way of unlisting set it
then, so it is never earlier than the unlisting, and a version changed
after it was unlisted counts from that later change. A content selector a
retention rule names can no longer be deleted (409) until no rule names it.
Policies stored before keep running as they did.
