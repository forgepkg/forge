An instance could fail to start while it imported a legacy `[oidc]` or
`[auth.upstream_basic]` block into its realm. This happened when a realm
created at the same time took the priority the import had read for the
`oidc` realm, or when instances booting at once all inserted the missing
realm. The import failed on the realm table's unique key, and the instance
started only after a restart. The import now takes the lock realm creates
take. It waits for them and appends after them, and it leaves alone a realm
another instance imported in the meantime.
