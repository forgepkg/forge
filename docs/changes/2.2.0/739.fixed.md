An instance could fail to start on every boot while it imported a legacy
`[auth.upstream_basic]` block whose slot in `[auth] providers` another realm
held, such as a realm created through the admin API before the block was
added. The first import also failed when another realm held the slot the
built-in `local` realm moves to. The import now puts the realm after the last
one, leaves `local` where it is, and logs a warning that names the realm
holding the slot.
