An apt package's `control` file could be 1 MiB, and an index generation
held every list's text and copies at once, a few times each package's
control file per architecture: a writer's few hundred tiny packages with
large descriptions made every `apt-get update` OOM-kill the instance. A
`control` file over 64 KiB is refused with `400`, on upload and on import;
an index's size is checked before its lists are made, and they are made,
stored and dropped one at a time. A package stored before with a larger
`control` file is left out of the indexes (it stays in the pool) instead of
failing them ([apt repositories](docs/apt.md#uploading-packages)).
