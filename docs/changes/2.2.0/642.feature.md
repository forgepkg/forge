Imports read the source through the format's own protocol instead of Nexus'
REST API, so a hosted repository can import from any server that speaks it:
a NuGet v3 feed (Nexus' `/repository/<name>/index.json`, Artifactory,
ProGet, BaGet, another Forge) or a registry (Nexus, Harbor, a `distribution`
registry, another Forge), through its catalog, tag lists and referrers API,
or through the referrers tag schema where it has none. An import can name
its package IDs or images instead (`names`), for a feed without a search, a
package Nexus' search misses, or a registry without a catalog. A NuGet
version is verified against the SHA-512 a feed's registration lists, and a
second run downloads nothing Forge holds with it. An imported version counts
as downloaded at its import, so retention's `not_downloaded_for_days` does
not delete it right after; nuget.org's `1900-01-01` is no publish time. The
import is named neutrally: **Import** in the web UI, `docs/import.md`.
