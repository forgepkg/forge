The web UI's package page of a proxy, or of a group with proxy members, asked
the upstream on every view once the package's listing was older than the
proxy's metadata TTL, one step and one member after another: the page was
slow, often showed less than Forge had cached, and opening it added the
package to the browse list. The page now answers from what Forge holds,
without asking the upstream, and says how old that is ("Cached 3 h ago").
Once that is past the metadata TTL, the page refreshes the package in the
background and shows what it found when it is done. Any reader of the
repository can also refresh the package with **Refresh from upstream**. A
package the proxy holds nothing of shows as not cached, with the same
button, instead of being fetched by looking at it.
