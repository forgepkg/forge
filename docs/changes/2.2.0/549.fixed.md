With telemetry off, two of its measurements still cost work: retention read
each repository's size (a `SUM` over its assets, images or files) before
every run and again after one that deleted something, and the connection
pool emitted an event on every acquire for a metrics layer that recorded
nothing. Both now happen only with `telemetry.metrics` on; a dry run and a
disabled policy, which free nothing, no longer read the size either.
