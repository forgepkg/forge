Traffic: `traffic.maxmind_url` must be `https://`, since every download
sends the MaxMind account ID and license key there. Forge no longer starts
with an `http://` one, which sent them in clear, unless its host is loopback
(a mirror on the same machine). And **Turn off** under **Admin → Traffic →
Settings → Geolocation** is no longer undone by a download running at that
moment: the download, on whichever instance it runs, is discarded instead of
putting the databases back in the bucket, as is one that was started before
the credentials were set again.
