An npm tarball with data after the two zero blocks that end its archive, or
after the zero byte that pads its gzip stream, was refused, though npm
installs it; through a proxy repository such a package answered 502 for the
not-found TTL. Forge now ignores that data where npm (node-tar and Node's
zlib) ignores it. A block after a lone zero block, which npm reads as a
header, is still refused.
