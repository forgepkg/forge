The Helm chart set no `OTEL_*` variable for a telemetry signal turned on
through the `config` pass-through (`config.telemetry.metrics: true`), so
Forge exported to `http://localhost:4318` and ignored `telemetry.endpoint`,
`telemetry.headersSecret`, the sampler and the resource attributes. Such a
signal now gets the same `OTEL_*` environment as one turned on with
`telemetry.metrics`, `traces` or `logs`.
