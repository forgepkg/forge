`forge.worker.last_success.time` was recorded only when a worker's pass
succeeded, so with delta temporality
(`OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE=delta`) only the export
right after a successful pass carried it. Between the passes of a slow worker
the series went stale, and when a worker stalled it vanished, so the
`ForgeWorkerStalled` alert could not fire. It is now reported on every export
for every worker that has had a successful pass, with the same name, unit and
`forge.worker` attribute.
