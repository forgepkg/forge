An apt repository accepted an imported signing key that was expired or
revoked, or whose signing subkey was, and signed `InRelease` and
`Release.gpg` with it: `apt-get update` then failed for every client
(`EXPKEYSIG`, `REVKEYSIG`). The import now refuses a key whose primary key is
expired or revoked, with the reason, and skips an expired or revoked signing
subkey (refusing the key when no key that may sign is left). A key that
expires later is accepted, and **Signing keys** and
`GET /admin/repositories/{name}/signing-keys` (`expires_at`) show when. Once
it has expired it signs no longer: the repository's other keys sign the
index, and when none is left the index is not made and its files answer 503
with the reason until a key is added ([apt](docs/apt.md#signing-keys)).
