Forge always serves the web UI: `web.enabled` was removed. A configuration
that sets `enabled = false` under `[web]`, or `FORGE_WEB__ENABLED=false`,
refuses to start: remove the setting. A leftover `enabled = true` changes
nothing. A deployment without the web UI lacked the administration screens,
the page on which an invited user chooses their password and the page that
approves an `npm login` in the browser.
