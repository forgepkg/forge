An import's scan failed as a whole, and every resume failed again at the
same place, when the source refused or failed on one package or image it
listed: a registry's `tags/list` answering 401 for an image the import's user
may not pull, or a NuGet feed or npm registry answering 403 or 500 for one
package. That name is now an item that fails with the source's answer, after
the retries of a failure that may pass, and the scan goes on with the next
name. Only a failure of the listing itself (a catalog, a search, `/-/all`), or
a source that cannot be reached at all, fails the import.
