When the traffic settings could not be read, for example while PostgreSQL
failed over, the traffic statistics fell back to the defaults: an instance
starting during the outage recorded client addresses an administrator had
turned off, and its hourly pruning deleted the days past the default
retention rather than the one set; an instance stopping wrote its last
minute's client addresses the same way. An instance now keeps the settings
it last read, and until it has read them once it writes no client address
and prunes nothing. A failed read of the MaxMind state after a download
no longer overwrites the stored account ID.
