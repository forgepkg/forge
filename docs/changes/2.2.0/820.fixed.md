Reading an apt package's control file compared each of its fields with every
field before it, so a writer could upload a `.deb` whose 1 MiB control file
of about 129,000 short fields cost some 20 s of CPU, on the upload and again
on every index generation of its repository while that held the index lock.
Each field is now checked against the earlier ones in constant time, and a
paragraph of more than 256 fields is refused: an upload with such a control
file answers 400, and an apt import fails on such a `Release`. Real control
files, `Packages` entries and `Release` files hold a few dozen fields.
