An import copies an npm registry's packages into a hosted npm repository:
Nexus' `/repository/<name>`, Verdaccio, Artifactory or another Forge. The
packages come from the registry's search, or from its `/-/all` where the
search lists nothing (Nexus, Verdaccio), or from the packages and scopes
(`@acme`) the import names. Every version's tarball is downloaded from the
import's URL, whatever host `dist.tarball` names, and checked against
`dist.integrity` (or `dist.shasum` alone); its publish time comes from the
packument's `time`, and its deprecation comes along. The dist-tags are set
once their versions are in Forge. A second run downloads only what is new
and moves the dist-tags the source moved; a dist-tag or deprecation changed
in Forge follows `on_conflict`. The web UI offers the import on npm hosted
repositories.
