The web UI's package page looked for a README in the latest version's
manifest for every format, although only npm's manifests carry one. For a
NuGet package each page view read the stored manifest for nothing, and a
refresh of a proxy's package from its upstream (off the request once the
listing is stale, or with **Refresh from upstream**) asked the upstream for
the `.nuspec` of a version nobody had downloaded, or downloaded the whole
package where the upstream serves no manifest. The manifest is now read
only for a format that shows a README. A group also loaded its memberships
and the caller's grants again for each of the page's reads; a request now
loads them once.
