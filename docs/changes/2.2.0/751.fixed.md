A NuGet import brought every version in listed, also those the source
feed had unlisted, and a version unlisted at the source after a first
import stayed listed in Forge on every later run. A version the feed's
registration lists as unlisted (nuget.org's `1900-01-01` publish time
counts as unlisted) is now unlisted in Forge, and one the source unlists
or relists later follows it on the next run. A listing changed in Forge
since is a conflict, decided by the import's conflict policy.
