An import copies an apt repository's packages into a hosted apt repository:
Nexus' `/repository/<name>`, a static repository a web server serves (made
with `dpkg-scanpackages` or `apt-ftparchive`) or another Forge. The import
takes the repository's base URL and a distribution (by default the hosted
repository's own), and reads `dists/<distribution>/InRelease` (or
`Release`); given the source's public key, only a `Release` that key signed.
Each `Packages` index is checked against the SHA-256 `Release` lists for it,
and each `.deb` against the size and SHA-256 its index lists, then written
under the component the source lists it in. A package Forge holds with the
same SHA-256 is skipped without a download, so a second run copies only
what is new. The web UI offers the import on apt hosted repositories.
