An apt repository kept the `by-hash/` copies of an index for a day from
when that index was made, not from when a newer one replaced it: after a
publish into a repository whose index was more than a day old, a client
that had just fetched the previous `InRelease` got `404` for its by-hash
files, fell back to the new `Packages`, and `apt-get update` failed with
"Hash Sum mismatch" until it ran again. The copies now stay a day after a
newer index replaces theirs, as documented. Copies that no index names
when Forge is upgraded stay a day longer, once.
