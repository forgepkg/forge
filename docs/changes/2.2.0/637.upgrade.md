Forge requires PostgreSQL 18 or newer; it asked for 15 or newer before. On
PostgreSQL 15 to 17, upgrade PostgreSQL first (`pg_upgrade`, or a dump and
restore), then Forge: Forge does not check the server's version, and on an
older server a query that uses what 18 added fails. The in-cluster PostgreSQL
of the Helm chart and of the kustomize component runs 18 already.
