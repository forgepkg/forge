An apt proxy asked for a pool file it had not cached yet searched the
upstream's `Packages` index for the file's size and SHA-256 with no limit on
the length of a line, so an index without line breaks, from a hostile
upstream or from anyone on the path to an `http://` mirror, made each such
request hold up to 1 GiB. The proxy now reads the index a line of at most
256 KiB at a time, far above any real `Packages` line, and gives up on an
index with a longer line: the file is then fetched unverified, as when the
index does not list it.
