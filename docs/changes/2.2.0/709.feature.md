**Admin → Traffic** shows what every instance answered: requests over time,
data sent, 4xx and 5xx answers and latency, by repository, surface and
status, and the 20 client networks with the most requests. Each client opens
its own view with its requests from a request log. Every instance writes its
counts to Forge's bucket once a minute, as Parquet files under `traffic/v1/`
that DuckDB or pandas read too, so the page covers all instances without
Redis. What is recorded (client addresses and the request log can be
switched off) and how long each part is kept (statistics 400 days, top
clients 30, request log 7 by default) is set under **Admin → Traffic →
Settings** (`/admin/settings/traffic`). The listing of these files makes
Forge call `ListObjectsV2`, which the documented `s3:ListBucket` permission
already allows.
