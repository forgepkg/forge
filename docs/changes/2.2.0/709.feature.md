**Admin → Traffic** shows how many requests each client made to each
repository, day by day, over every instance, and the countries and
autonomous systems they came from. Each list narrows the view: a repository
shows where its requests came from, a country, network or client what it
used. Every instance writes its daily counts to Forge's bucket once a
minute, as Parquet files under `traffic/v1/` that DuckDB or pandas read too,
so the page covers all instances without Redis. Countries and networks come
from MaxMind's GeoLite2 databases, which Forge downloads every three days
with a MaxMind account ID and license key set under **Admin → Traffic →
Settings**, or which can be put in the bucket by hand. Recording, client
addresses and the retention (90 days by default) are set there too.
