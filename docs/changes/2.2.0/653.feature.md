An administrator can accept an invited user's invitation for them, with a
password they set: **Accept invitation** on the user's page under
**Admin → Users**, or `POST /admin/users/{id}/invitation/accept`. It hands an
account over ready to use (an install without email, a user without a
mailbox) whether its invitation is still live or has expired: the password
becomes the account's, the account is active, and the invitation link stops
working. The password follows the invitation page's rules (at least 12
characters); an account whose user chose a password already, an account of
another realm, a service account and a deactivated account are refused. This
is the only way an administrator sets another person's password.
