Imports drop the Nexus name. The `nexus_import` and `nexus_import_item`
tables are `repository_import` and `repository_import_item`. In the admin
API's import view, `url` is the source (a feed's service index or a
registry), `nexus_version` is `source_server` (the `Server` header the
source answered with), and `source_repository`, `registry_url` and the
progress's `assets` and `size` are gone; `names` and `source_total` are new.
The previous request, a Nexus `url` and `repository` (and `registry_url`),
is still accepted. An import stored before the upgrade still lists; resumed,
its scan starts again, because its cursor was a Nexus `continuationToken`,
and what it copied already comes out `identical`. Nexus' REST API is no
longer read, so a version's last download and uploader in Nexus are not
carried over.
