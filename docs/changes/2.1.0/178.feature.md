Prometheus metrics at `GET /metrics` on a listener of their own
(`server.metrics_bind`, optionally behind `server.metrics_token`), never on
the main one: requests by surface, proxy lookups by outcome with upstream
latency, bytes and 429s, S3 operations, the circuit breaker, the blob
cache's counters, staging space, the outbox backlog, cache hits, the
connection pool, every background worker's passes and restarts, retention,
sign-ins, and an inventory of repositories, versions and stored bytes. No
label carries a package, version, image, user or path; repository names can
be turned off with `metrics.per_repository = false`. The Helm chart and the
kustomize base expose the port, with an opt-in `ServiceMonitor` /
`PodMonitor` and a NetworkPolicy rule, and `deploy/monitoring` has a Grafana
dashboard and example alerts. See the deployment guide's Metrics section.
